# Roadmap

## Demonstrated

- [x] Interactive certificate form and English preview
- [x] Existing Metaplex Core asset on Solana Devnet
- [x] Public lookup of asset owner and collection
- [x] Read-only judging demo with issuance disabled
- [x] English three-minute demo video
- [x] Browser byte, hashing and signing regression tests

## Before a pilot

- [ ] Validate a fresh image upload, metadata upload and mint with a wallet
- [ ] Add issuer onboarding and a verified issuer registry
- [ ] Replace browser-only issuance history with indexed records
- [ ] Implement revocation that verifiers can independently check
- [ ] Define consent, data retention and correction procedures
- [ ] Test certificate rendering in supported wallets

## After pilot validation

- [ ] Run a small course-provider pilot and collect reviewer feedback
- [ ] Evaluate organizer subscriptions and per-certificate pricing
- [ ] Review security and operational costs before a mainnet launch

These are planned milestones, not claims of completed features, adoption or revenue.
