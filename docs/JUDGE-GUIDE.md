# Judge guide

Open the [public demo](https://alishkka.github.io/NFT-Certificates-StartupCourse/). It intentionally disables issuance and wallet actions.

1. Change the name and course in the form. Observe the preview.
2. Confirm **ДЕМО: ВЫПУСК ОТКЛЮЧЁН** is disabled.
3. Scroll to **Существующие сертификаты** and click **Проверить** for certificate #1.
4. Wait for a real Devnet lookup and inspect the owner and collection.
5. Open Solana Explorer. Its network should be **Devnet**.

[Direct verification](https://alishkka.github.io/NFT-Certificates-StartupCourse/?certificate=FxRV2Y2fbJzfeMcQgGHjd8SwLoXX2xfHAvudrqofxufQ)

[Solana Explorer](https://explorer.solana.com/address/FxRV2Y2fbJzfeMcQgGHjd8SwLoXX2xfHAvudrqofxufQ?cluster=devnet)

No real funds or wallet signature are required. Demo edits cannot change the existing certificate. RPC outages may temporarily prevent lookup. The example's empty metadata URI and missing wallet image are documented MVP limitations.
