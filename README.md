# NFTStart

Сырой MVP для выпуска непередаваемых NFT-сертификатов в Solana Devnet.

## Возможности

- подключение администраторского кошелька Phantom;
- автоматическое создание коллекции Metaplex Core;
- генерация SVG-карточки и загрузка метаданных через Irys;
- выпуск Core Asset сразу на адрес получателя;
- блокировка передачи через `PermanentFreezeDelegate`;
- проверка NFT и его коллекции по адресу;
- локальный журнал выпусков и локальная отметка отзыва.

## Запуск

Требуется Node.js 22+ и Phantom с включённой Solana Devnet.

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`.

## Первый выпуск

1. Подключите Phantom.
2. Получите Devnet SOL через кнопку в интерфейсе или `https://faucet.solana.com`.
3. Укажите ФИО, номер, дату, программу и Solana-адрес получателя.
4. Нажмите «Выпустить NFT» и подтвердите операции в Phantom.
5. Первый выпуск сначала создаст официальную коллекцию, затем сам сертификат.

## Ограничения MVP

- проект работает только в Devnet;
- поддержан Phantom; MetaMask/Solana Wallet Standard добавляется после проверки основного потока;
- журнал и статус отзыва хранятся в `localStorage` текущего браузера;
- публичное on-chain погашение и серверная база будут нужны перед production;
- Irys может потребовать отдельное пополнение баланса загрузчика при больших файлах.
